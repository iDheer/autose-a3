Adds an optional `limit` argument to `Table.search()` (and therefore `TinyDB.search()`).

The scan stops as soon as `limit` matching documents have been collected, so `db.search(q, limit=10)` no longer builds the full result list. Results keep the same order as before, and the result is cached exactly like before, so repeated searches stay fast. Without `limit` nothing changes.

Tests: `tests/test_search_limit.py`. Full suite passes; mypy clean.
