Fixes the fragment() cache issue.

`Query.fragment` built its hash as `('fragment', freeze(document))`, without the query path, so `Query().home.fragment(d)` and `Query().work.fragment(d)` were equal and shared one query-cache entry. The hash now includes `self._path`, like every other query operation (ARCHITECTURE.md C2).

Tests: `tests/test_fragment_paths.py` covers the reported scenario and hash equality. Full suite passes.
