# Runs

Every real run of the workflow on the fork [iDheer/tinydb](https://github.com/iDheer/tinydb), all on
2026-11-15. All artifacts of every run (spec, design, diff, test report, PR body, reviews, full agent
transcripts and metrics) are on the fork's [`autose-artifacts`](https://github.com/iDheer/tinydb/tree/autose-artifacts)
branch under `issue-N/run-<run id>-<attempt>/`, and seeded-PR reviews are under `experiments/A/`.
Numbers in [`results.csv`](results.csv), [`stage_checks.csv`](stage_checks.csv),
[`experiment_A.csv`](experiment_A.csv) and [`experiment_B_strength.json`](experiment_B_strength.json)
are generated by `experiment/scripts/collect_results.py` and `test_strength.py` from those artifacts.
Hidden tests were run locally with `eval_hidden.py`; they never entered the fork.

**Total model use:** 12 build runs + 16 reviews = **$6.31** at API list prices, as reported by the SDK.
Billing went through a Claude Pro subscription token, so no money was charged beyond the
subscription; extra usage was off, which acts as the hard spending limit. Tokens: 574 uncached input,
257,940 output, 4,111,975 cache-read and 783,162 cache-write ([`summary.json`](summary.json)).
